## Tech

Presentations are built with [Slidev](https://sli.dev/) — a Markdown-based slide framework powered by Vue.js. Slides are written in `slides.md` and rendered in the browser with themes, animations, and Mermaid diagrams.

## Usage

```bash
cd <talk-directory>
npm install
npm run dev
```
